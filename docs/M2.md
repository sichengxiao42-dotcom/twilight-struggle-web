# M2：本地早期战争

默认创建 `EARLY_WAR` 模式，保留 `createGame(seed, 'PRACTICE')` 供 M1 练习使用。没有改动远程仓库或部署。

## 引擎

- `actions.ts` 是不可变动作入口：校验当前操作方，复制局面，再应用动作。失败不会消耗原局面的卡牌或随机数。
- `engine.ts` 持有事件调度、决策、临时 / 持久效果和跨回合流程。`tasks` 为按顺序执行的可序列化任务队列；决策可以换操作方，但 `phasingSide` 始终保留核战争责任方。
- 行动开始保存影响力快照。对手事件先结算时，事件新放的影响力不会扩大本行动原本可用的 OPS 放置范围。
- 卡牌从手牌移至待结算区，执行完 OPS / 事件后进入弃牌堆；有效且带星的事件进入移出区。北约前置条件不满足、被叛逃者取消或用于太空竞赛的卡，不因星号被移出。
- `scoring.ts` 返回存在 / 优势 / 控制、战场国与超级大国邻接计分明细。台湾决议只在计分时改变战场属性。
- 所有随机结果沿用局面 seed 与 rngCalls；五年计划、战争、奥运会、太空和洗牌均可复现。

## 界面操作

1. 在金色国家框上点击完成开局布点。
2. 换人后点击“显示手牌”，点选卡牌阅读效果，再确定头条；双方选择后揭示。
3. 行动中可选事件、OPS 或太空。对手牌用于 OPS 时选择事件在前还是在后。
4. 事件选择由对应玩家处理；地图事件的合法目标会高亮。
5. 去斯大林化可提前结束移除，再将已移除的数量重新放置。特殊关系的两点必须在同一国。
6. 中国牌或越南奖励通过“区域奖励”预先选择；选择后目标被限制在对应地区，防止拿到奖励后转去其他地区。
7. 头条换人、事件换人都会隐藏手牌；CIA 公开的苏联手牌仅在美国玩家面板显示。

热座模式无法防止查看开发者工具，M3 已通过服务端视图裁剪实现联机隐藏信息，不能复用完整本地状态直接广播。

## 边界

包括原始早期牌、叛逃者和 104–106 三张早期可选牌；不包括零回合、中国内战变体、中晚期牌和十回合终局。前三回合结束只显示阶段完成，不添加虚构的终局计分或自动把当前领先者宣布为整局赢家。太空 8 格的额外行动轮属于完整游戏里程碑；正常前三回合无法到达该格。

游戏刷新会重置；导出存档、复盘播放器和网络房间留待后续。M3 房间和重连现已实现，使用说明见 [M3.md](M3.md)。

## 验证

`npm run check` 运行类型检查、ESLint、Node 测试和前后端生产构建。测试覆盖：

- M1 回归、所有 38 个事件入口的决策收尾；
- 头条保密与优先顺序、叛逃者、UN 禁作头条；
- 对手事件先后顺序、嵌套五年计划、CIA 核战争责任；
- 封锁修正 OPS、每国上限、去斯大林化、华沙条约及保护效果；
- 区域计分、台湾、中国牌、NORAD、特殊关系；
- 太空弃牌、VP 与可达特权、临时修正合并、回合结束；
- 20 个 seed 的流程模拟，检查牌张守恒、非负整数影响力、有限 VP / OPS 和无死锁。

浏览器下载在当前环境返回了无效安装包，因此尚未完成真实浏览器点击与视觉验收。类型检查与生产构建不替代视觉验收。
