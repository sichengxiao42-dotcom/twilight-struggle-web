## 拉取后运行

```bash
git pull --ff-only origin main
npm ci
npm run dev
```

图片和索引都是普通 Git 文件，不需要 Git LFS，也不需要安装 TTS 或再次导入素材。拉取后应有 55 个图片文件、110 条卡牌索引；前端在 `http://127.0.0.1:5173`。第一次拉取素材需要下载约 93 MiB 的原始图片，Git 实际传输量取决于压缩。
