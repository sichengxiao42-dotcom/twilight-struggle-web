# 基础陪练机器人

## 使用

创建房间 → 添加基础陪练 → 开始对局。尚未选边时默认玩家美国、机器人苏联；也可以先选边或随机分配。大厅可移除机器人，开始后不能替换对手。重开返回大厅并保留机器人席位，重新开始才发牌。机器人占一个席位，不允许第三人加入。

机器人自动完成开局布点、秘密头条、出牌、事件选择、影响力操作、政变、调整、太空竞赛、陷阱弃牌及回合确认。出牌沿用棋盘展示、最近出牌和日志。人类仍需自行完成自己的事件选择，即使该事件由机器人打出的牌触发。

## 决策与节奏

- 使用规则评分：优先完成计分牌、控制战场国、补足军事行动；适时使用有利事件，把危险对手牌送入太空。
- 避开显然导致核战的政变、古巴导弹危机期间政变和会输掉游戏的“战争游戏”。降核事件优先于 OPS 结算，以免先政变再降核。
- 不根据对手暗手、秘密头条、牌堆顺序或未来骰点评分。候选操作经 `apply` 校验；模拟结果不参与胜率比较。
- 这是规则评分的入门陪练，没有多步搜索和长期战略。随机弃牌触发事件等风险仍可能导致失败。
- 服务器每 700ms 执行一步，不要求玩家浏览器保持前台。所有人类连接断开时暂停，恢复连接后继续。

## 实现与验证

`packages/game-core/src/bot.ts` 负责选择单步操作，规则状态仍由 `apply` 唯一修改。`RoomStore` 管理机器人席位与行动权限；Socket.IO 每房间最多一个计时器，每步检查最新状态，重开、关闭和断线取消待执行行动。异常通过房间快照展示，可点击“重试陪练”，不会擅自跳过事件。

测试包含 16 个固定种子的机器人完整对局、全部卡牌事件后续决策、秘密信息独立性、核战保护、房间权限、断线暂停与恢复、真实 Socket.IO 自动行动及重开取消计时器。
