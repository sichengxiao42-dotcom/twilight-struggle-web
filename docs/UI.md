# 牌桌与卡牌操作

桌面采用固定三分区：棋盘靠左上占最大面积，手牌紧接棋盘下方，右侧固定展示当前阶段提示与卡牌操作。棋盘与手牌等宽，卡牌效果和确认按钮不会遮住棋盘。顶部保留撤销／菜单入口。联机设置、日志、持续效果和国家列表集中在可收起的菜单中。

## 一条操作主线

当前步骤固定在右栏顶部的任务卡中：18px 加粗标题、阵营色竖线，剩余 OPS 或开局影响力单独突出。部署指引压缩为一句话，额外规则默认折叠；“完成部署”进入原有的结束确认，不直接交接行动。常见部署任务卡约 140px 高，下方卡牌与资料区独立滚动；切换资料或选择卡牌时从内容顶部开始，任务提示始终保留。

公开出牌后，卡图与用途显示在棋盘相应超级大国位置：美国在左侧旗帜处，苏联在苏联区域。结算与等待结束确认期间持续显示；点击“结束回合”后，用约 0.32 秒的平移动画收入右栏固定的“最近出牌”入口。瞬间完成的牌至少停留约 1.1 秒再收起。右侧“出牌”标签可回看所有已完成的公开出牌、卡图、效果、阵营和用途。头条仅在双方确认并揭示后进入公开记录；对手事件接管操作不会提前收牌。记录随服务端局面同步，支持恢复与撤销；恢复历史不重播旧动画。系统减少动态效果时直接收起。

右栏外沿的索引标签可切换卡牌操作、地区局势、对局日志、规则速查、持续效果；联机时另有房间管理。未选牌时默认显示地区局势，列出双方在六大区域的状态、控制国与战场国数，以及当前计分预估。穿梭外交计入预估，但不修改真实控制数；东南亚单独列出。日志最新在上。点击手牌自动切回卡牌操作；查资料后再点同一张牌也会重新打开详情，只有在卡牌页再次点击才收回。当前步骤和结束行动按钮不随资料页切换隐藏；新出现的事件选择和结束确认会优先打开卡牌操作。窄屏标签横排，避免挤压内容。

进入页面时，右栏只显示“创建房间”和房间码加入表单，棋盘为无手牌的只读预览。进房后才出现选边大厅；双方在线并选边完成，再点击“开始对局”才发牌、显示当前阵营与手牌区域。本地热座从菜单主动开始。

1. 显示自己的手牌，点击底部卡头查看。等待阶段也能看牌。
2. 选择卡牌用途。头条、计分和符合条件的受困弃牌只有一个合法用途时会直接选中；其他情况由玩家选择。
3. 点击写明用途的确认按钮。需要国家目标的操作回到棋盘，根据高亮继续；需要事件选项时展开操作面板。

查看和切换卡牌不消耗手牌。右侧详情展示期间，棋盘和下方手牌仍可操作；另一张直接切换，同一张再次点击取消选牌。关闭按钮或 Esc 也能取消；点击棋盘空白处不会关闭固定操作区。没有居中弹窗、全屏遮罩和第二个重复的出牌表单。

## 减少错误和无效操作

- 非法用途显示原因：对手事件、太空 OPS／次数限制、计分牌、泥潭／捕熊陷阱、导弹嫉妒和中国牌限制。
- 古巴导弹危机期间，政变按钮提示先解除危机。
- 对手事件顺序和区域奖励仅在相关用途下出现。
- 点击高亮国家直接部署 1 点，也可从备用区拖入；选中国家保留加减控件，撤销自己最近的布点不会重新隐藏自己的手牌。
- 热座切换阵营时隐藏手牌；联机等待方仅可查看自己的牌。最终动作仍由规则引擎和服务器校验。
- 轨道棋子按阵营固定偏移，数值不变的棋子不再因排版重心变化要求拖动。
- 窄屏按棋盘、手牌、卡牌操作的顺序排列；卡头可横向滚动，操作区显示效果文字与用途按钮。减少动态效果的系统设置会关闭抬升动画。

## 验证

需要投骰的操作会弹出骰子浮窗：点击自己的骰子生成点数，查看后再点“继续结算”。调整等双方操作由双方依次掷骰。结果产生前不预填点数，确认前不应用骰子产生的地图变化。联机等待方可观看，机器人自动投自己的骰子；刷新重连保留已投点数。实现与测试见 [DICE.md](DICE.md)。

“弃／弃牌”面板显示美、苏两个牌堆，其余面板保留紧凑的双牌堆入口。点击任一牌堆打开原生模态浮窗，按出牌方平铺所有已结算的卡面，最新在前；支持切换阵营、内部滚动、关闭按钮、Esc 和点击遮罩关闭。浮窗使用浏览器模态焦点管理，关闭后回到入口。桌面按宽度排列卡面，窄屏两列。结算完成的牌飞入所属阵营牌堆。这里是用牌记录，包含弃牌、移出游戏、已洗回等记录，不改变规则引擎中的牌区。

自动测试涵盖只读预览、头条限制、对手事件、太空门槛与次数、受困弃牌、计分、中国牌、导弹嫉妒、古巴导弹危机、谷物出售，以及只有明确确认才消耗牌。

浏览器实测包括双方开局布点、头条交接和手牌隐藏、轨道实际拖放、用途选择、切换选牌、确认进入 OPS、地图部署、减号撤回与备用棋子拖放，并检查桌面和窄屏的布局。
