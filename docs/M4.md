# M4：中期、后期战争与完整十回合

## 范围

M4 把游戏从“早期战争三回合”扩展为完整的 10 回合标准对局，本地热座和联机房间都能使用。

- **卡牌**：豪华版 #1–110 全部录入。新增中期 48 张（#36–81、#107、#108）和后期 23 张（#82–102、#109、#110），全部事件均已实现。
- **回合流程**：第 4 回合起每回合 7 个行动轮、手牌 9 张；第 4、8 回合开始时，把中期、后期卡牌洗入剩余牌堆（弃牌堆不参与，规则 4.4）；第 10 回合结束后进行终局计分。
- **第 8 个行动轮**：太空竞赛第 8 格（空间站，仅先到者）或“北海油田”提供，可以放弃。
- **计分**：新增中美洲、非洲、南美洲、东南亚计分。终局计分逐区计算，中国牌持有者 +1；终局时不因 20 VP 自动获胜，但控制欧洲仍直接获胜（规则 10.3.2）。
- **持续效果**：生效中的事件显示在轨道下方的“生效中”一栏。

## 需要特殊交互的牌

| 牌 | 网页上的处理 |
|---|---|
| 泥潭 / 捕熊陷阱 | 行动轮出现“弃牌掷骰”面板；没有可弃的牌时只能打计分牌，连计分牌都没有时可以跳过 |
| 古巴导弹危机 | 受影响的一方在自己的行动轮有“移除 2 点影响力以取消”按钮；期间任何政变都直接判负 |
| 导弹嫉妒 | 换牌后，对方下一行动轮只能把“导弹嫉妒”用作 OPS |
| 向苏联出售谷物 | 美国选择打出抽到的牌（事件 / OPS / 太空）或交还 |
| “我们会埋葬你们” | 美国下一次行动前结算；以事件打出联合国干预可以取消 |
| 军政府、推倒这堵墙、奥尔特加、切·格瓦拉 | 免费政变：不计军事行动，无视 DEFCON 地区限制，战场国仍降 DEFCON |
| 穿梭外交 | 牌放在美国面前，下一次中东或亚洲计分用掉后才进弃牌堆 |
| “不要问”、我们的人在德黑兰、星球大战、战略武器限制谈判 | 逐张选择弃牌或取牌 |

## 规则解释（规则书没有写明，按以下方式实现）

1. **免费调整**（军政府、推倒这堵墙）和免费政变一样无视 DEFCON 地区限制。
2. **穿梭外交**：被扣除的那个苏联战场国同时从“控制国家数”中扣除。
3. **剑桥五杰**看到东南亚计分牌时，可以在整个亚洲放置影响力。
4. **导弹嫉妒**按卡面印刷的 OPS 比较大小，不计修正。
5. **向苏联出售谷物**：抽到的牌也可以用于太空竞赛，受正常次数限制。
6. **对手阵营的牌不能“作为事件”打出**（规则 7.1），只能用作 OPS（事件照常发生）或用于太空竞赛。
7. **前置条件**不满足时（如“厨房辩论”美国战场国不占优、“战争游戏” DEFCON 不为 2、“星球大战”太空不领先），按规则 5.2 视为事件未发生，带星号的牌回到弃牌堆，不移出游戏。

## 测试

`npm test` 共 73 项，其中 `packages/game-core/test/midlate.test.ts` 覆盖：

- 71 张中后期事件逐一打出后都能回到下一个行动轮，牌的去向正确。
- 回合数、第 8 行动轮、牌堆加入时机、终局计分、欧洲控制、东南亚计分、穿梭外交。
- 泥潭、古巴导弹危机、核潜艇、导弹嫉妒、出售谷物、“我们会埋葬你们”、U-2、花朵力量、邪恶帝国、各种政变 / 调整修正、免费政变、切·格瓦拉二次政变、中国牌相关事件、前置 / 取消关系、战争游戏、星球大战、战略武器限制谈判、“不要问”、我们的人在德黑兰、恐怖主义、艾姆斯。
- **40 局随机种子完整对局**：每一步检查没有卡死、没有丢牌或重复牌、影响力和 DEFCON 合法；至少有对局打到后期并进入终局计分。

另在浏览器里用脚本点击真实界面完整打了一局，从开局一直打到第 10 回合终局计分，过程中出现过泥潭、出售谷物、穿梭外交、切·格瓦拉等特殊流程，控制台没有报错。
