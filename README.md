# 冷战热斗 · 网页版

《冷战热斗》（Twilight Struggle）的浏览器双人对战实现：TypeScript 规则引擎 + React 前端 + Socket.IO 联机。

- 企划书：[docs/PROPOSAL.md](docs/PROPOSAL.md)
- 规则摘要：[docs/RULES.md](docs/RULES.md)
- 原版素材导入：[docs/ASSETS.md](docs/ASSETS.md)
- 生产运行与部署准备：[docs/DEPLOYMENT.md](docs/DEPLOYMENT.md)

> 《冷战热斗》© GMT Games。本私有仓库按项目所有者要求收录 TTS 中文模组的卡图、地图和标记图片；来源及校验记录见 [素材清单](docs/ASSET_INVENTORY.json)。

中文卡图 #1–110、地图和辅助素材已随仓库提交，克隆或拉取后无需另行导入。英文素材和原始模组缓存不在当前仓库文件中。

## 开发

需要 Node.js ≥ 22.12。

```bash
npm install
npm run dev      # 前端 http://127.0.0.1:5173，服务端 :3001
npm run check    # 类型检查 + lint + 测试 + 构建
npm run smoke:production # 检查生产构建的网页和联机
npm start        # 构建后，以同一端口托管网页和联机
```

## 结构

| 目录 | 内容 |
|---|---|
| `packages/shared` | 公共类型、Socket 协议 |
| `packages/game-core` | 纯函数规则引擎、地图与卡牌数据 |
| `apps/web` | React 前端 |
| `apps/server` | Socket.IO 服务端 |
| `tools` | TTS 素材导入脚本 |

**边界**：支持本地热座和双人房间；尚未部署到公网。第 3 回合结束后进入“早期战争完成”，只展示当前 VP，不执行十回合终局计分，也不宣称采用独立的官方早期战争剧本。中晚期卡牌、完整终局与复盘另属后续里程碑。本地热座刷新会重开；联机模式的同一标签页刷新可以恢复。房间只存内存，服务重启会丢失；尚无持久化存档。

运行 `npm run dev` 后打开前端地址。实现细节、规则参考和测试范围见 [M2 说明](docs/M2.md)。

生产托管已接入：构建后运行 `npm start`，同一个 Node 服务提供网页、中文素材和 Socket.IO。`render.yaml` 已准备并通过官方 JSON Schema 校验，尚未实际部署；平台校验和上线步骤见部署说明。
