# 冷战热斗 · 网页版

《冷战热斗》（Twilight Struggle）的浏览器双人对战实现：TypeScript 规则引擎 + React 前端 + Socket.IO 联机。

- 企划书：[docs/PROPOSAL.md](docs/PROPOSAL.md)
- 规则摘要：[docs/RULES.md](docs/RULES.md)
- 原版素材导入：[docs/ASSETS.md](docs/ASSETS.md)
- 生产运行与部署准备：[docs/DEPLOYMENT.md](docs/DEPLOYMENT.md)

> 《冷战热斗》© GMT Games。本私有仓库按项目所有者要求收录 TTS 中文模组的卡图、地图和标记图片；来源及校验记录见 [素材清单](docs/ASSET_INVENTORY.json)。

中文卡图 #1–110、地图和辅助素材已随仓库提交，克隆或拉取后无需另行导入。英文素材和原始模组缓存不在当前仓库文件中。

部署影响力时，直接点击棋盘上金框国家的国名栏或影响力格即可，每次部署 1 点；地图下方显示实际部署结果。侧边栏国名按钮也可使用，两种入口共用规则校验并同步更新。

## 开发

需要 Node.js ≥ 22.12。

```bash
npm install
npm run dev      # 前端 http://127.0.0.1:5173，服务端 :3001
npm run check    # 类型检查 + lint + 测试 + 构建
npm run smoke:production # 检查生产构建的网页和联机
npm start        # 构建后，以同一端口托管网页和联机
```

## 结构

| 目录 | 内容 |
|---|---|
| `packages/shared` | 公共类型、Socket 协议 |
| `packages/game-core` | 纯函数规则引擎、地图与卡牌数据 |
| `apps/web` | React 前端 |
| `apps/server` | Socket.IO 服务端 |
| `tools` | TTS 素材导入脚本 |

## 进度

界面采用与棋盘统一的复古纸质风格（暖灰米底、象牙白面板、墨色文字、砖红／灰蓝阵营色）：桌面地图居左、操作区固定在右、手牌位于地图下方；窄屏自动改为单列。顶部只显示当前一步的操作提示，完成后自动切换下一条；不再显示额外局势数据栏、完整流程条或后续阶段预告，局势数据仍可在地图轨道查看。地图支持缩放与合法国家快捷选择，联机设置、玩法速查和日志可折叠。热座交接及切换房间时手牌自动隐藏。

当前完成 **M4 完整十回合**：早期、中期、后期全部 110 张卡牌，第 4、8 回合加入新牌，第 10 回合终局计分，详见 [M4.md](docs/M4.md)。

联机（M3）：
- 创建房间、选择阵营、邀请链接、自动重连及同标签页身份恢复。
- 服务端权威结算、按阵营裁剪视图、请求去重与版本校验；使用说明见 [M3.md](docs/M3.md)。

早期战争基础（M2，现为标准对局的前三回合）：
- 苏联东欧 6 点 / 美国西欧 7 点开局布点，随后暗选头条；OPS 较高的头条先执行，同点美国优先。
- 共 39 张早期卡牌（含中国牌和 3 张早期可选牌）的机制、中文简述及交互；其中 38 张可结算事件，中国牌只用于 OPS。
- 可序列化事件决策队列；对手事件可选择在 OPS 前或后执行；有效的带星事件移出游戏。
- 欧洲 / 亚洲 / 中东计分，欧洲控制获胜、±20 VP 获胜、核战争及持有计分牌判负。
- 中国牌传递及亚洲奖励，越南区域奖励、遏制 / 清洗修正、北约 / 美日保护、NORAD、太空竞赛基础操作和早期可达特权。
- 回合末军事行动结算、翻转中国牌、清理临时效果、改善 DEFCON、补牌和弃牌洗回。
- SVG 示意棋盘、目标高亮、相邻连线、按阵营交接隐藏手牌、卡牌详情、出牌方式及事件选择面板。
- 可切换回 M1 OPS 练习模式。

**边界**：支持本地热座和双人房间；尚未部署到公网。零回合扩展、复盘和 AI 尚未实现。本地热座刷新会重开；联机模式的同一标签页刷新可以恢复。房间只存内存，服务重启会丢失；尚无持久化存档。

运行 `npm run dev` 后打开前端地址。实现细节、规则参考和测试范围见 [M2 说明](docs/M2.md)。

生产托管已接入：构建后运行 `npm start`，同一个 Node 服务提供网页、中文素材和 Socket.IO。`render.yaml` 已准备并通过官方 JSON Schema 校验，尚未实际部署；平台校验和上线步骤见部署说明。
