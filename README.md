# 冷战热斗 · 网页版

《冷战热斗》（Twilight Struggle）的浏览器双人对战实现：TypeScript 规则引擎 + React 前端 + Socket.IO 联机。

- 企划书：[docs/PROPOSAL.md](docs/PROPOSAL.md)
- 规则摘要：[docs/RULES.md](docs/RULES.md)
- 原版素材导入：[docs/ASSETS.md](docs/ASSETS.md)
- 生产运行与部署准备：[docs/DEPLOYMENT.md](docs/DEPLOYMENT.md)

> 《冷战热斗》© GMT Games。本私有仓库按项目所有者要求收录 TTS 中文模组的卡图、地图和标记图片；来源及校验记录见 [素材清单](docs/ASSET_INVENTORY.json)。

中文卡图 #1–110、地图和辅助素材已随仓库提交，克隆或拉取后无需另行导入。英文素材和原始模组缓存不在当前仓库文件中。

部署影响力时，先点击棋盘上的金框国家，再用棋盘上方的加减面板调整。＋ 部署 1 点，− 撤回该国最近的一次放置并恢复消耗的点数；减号不会删除原有影响力，也不会撤回其他国家的操作。地图高亮当前选定国家，面板同步显示双方影响力和每点 OPS 消耗。备用棋子拖动仍可直接部署。

## 开发

需要 Node.js ≥ 22.12。

```bash
npm install
npm run dev      # 前端 http://127.0.0.1:5173，服务端 :3001
npm run check    # 类型检查 + lint + 测试 + 构建
npm run smoke:production # 检查生产构建的网页和联机
npm start        # 构建后，以同一端口托管网页和联机
```

## 进度

界面采用与棋盘统一的复古纸质风格（暖灰米底、象牙白面板、墨色文字、砖红／灰蓝阵营色）：桌面地图居左、操作区固定在右、手牌位于地图下方；窄屏自动改为单列。顶部只显示当前一步的操作提示，完成后自动切换下一条；不再显示额外局势数据栏、完整流程条或后续阶段预告，局势数据仍可在地图轨道查看。地图支持缩放与合法国家快捷选择，联机设置、玩法速查和日志可折叠。热座交接及切换房间时手牌自动隐藏。

### 棋盘直接操作

- 从棋盘上方的苏／美备用区拖动棋子到合法国家，部署 1 点影响力；事件要求移除时，将对应国家棋子拖回同色备用区。
- 去斯大林化支持直接从来源国家拖到目标国家，逐点转移，来源数量与目的地上限由规则引擎校验。
- 回合、行动轮、DEFCON、VP、太空与军事行动轨道变化后，拖动标记到高亮落点，再继续操作；也可聚焦标记后按 Enter。非法落点返回原位。
- 点击已展示的手牌，直接在弹窗中选择头条、事件、OPS、太空或受困弃牌；侧边栏入口保留。

轨道数值仍由规则引擎结算，拖动负责摆放本机的可视标记，不允许任意改分。联机各客户端独立完成摆放，刷新后标记与服务器数值同步；本机摆放不会暂停对手。


### 撤销与牌桌布局

棋盘占据整行，原指挥席与手牌栏合并在棋盘下方的操作区。桌面端操作说明与手牌并列，窄屏上下排列，手牌可横向滚动。

点击“撤销上一步”可逐步恢复放置、出牌或事件选择前的完整局面（最多保留 32 步）。本地热座可撤销最近操作；联机只允许撤销自己最近的连续操作，对方一旦执行操作，此前的撤销记录即清空。撤销由服务端执行并同步双方，局面版本继续递增，重复请求不会重复撤销。已公开的信息无法从玩家记忆中收回，因此此功能适合朋友间纠正误操作。撤销也会将可视轨道标记同步到恢复后的数值。

桌面端采用同屏牌桌布局：棋盘根据剩余视口高度等比适应，右侧保留可滚动操作说明与三列紧凑手牌；地图放大在棋盘容器内滚动，100% 恢复同屏适应。打开国家影响力调整栏时，地图自动让出高度；窄屏继续使用单列布局。
